Ingeniero de software · Python, datos y agentes de IA

Ingeniero electricista (Universidad de Carabobo, 2001) y desarrollador backend, actualmente Software Engineer III en Asistensi Global Insurance. Dos décadas de Python en petróleo y gas, ingeniería cloud y de datos, inteligencia de negocios e insurtech.

Hoy la mayor parte de mi trabajo es IA agéntica: un framework multiagente sobre LangGraph, una terminal agéntica en Go, servidores MCP y componentes de Reflex que llevan librerías de React a Python.
