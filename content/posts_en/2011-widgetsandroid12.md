Title: Remotely controlling a Debian computer from Android with gmote
Date: 2011-04-08 09:00
Category: Demostración Aplicación para Android
Tags: Android, Linux, Debian, gnome
lang: en
translation: true


Gmote is an application written in java that lets you control the mouse and keyboard.

The gmote link is [here](http://www.gmote.org/) .

![Página de gmote](./images/gmote1.png)

To install it on android, search for gmote in the market and you will find it as shown in the figure.

![Market android](./images/marketandroid.png)

Once it is installed on the android, all that is left is to download the Linux application from the following [link](http://marcsto.googlepages.com/GmoteServerLinux2.0.0.tar.gz).

After unpacking the file, run GmoteServer.sh.

![Gmote Server ](./images/gmoteserver.png)

Configure the wifi access of the Android.

![Gmote Android](./images/gmoteandroid.png)

On the Android device, look in the applications and run gmote.

![Aplicaciones Android](./images/appsandroid.png)

The music player control screen appears; press menu on the phone and Touchpad appears among the options.

![Gmote touchpad](./images/gmotetouchpad1.png)

When you press TouchPad you already have control of the mouse on the computer.

![Gmote resultado](./images/gmoteresultado.png)

Clicking the keyboard symbol lets us type remotely on the computer.

This gmote option is useful for controlling presentations remotely.
