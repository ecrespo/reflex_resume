On the Python Argentina mailing list they shared the link to an Android application that
adds support for writing programs in python; the application is called android-scripting,
and it gives users a series of scripting languages,
python among them.

The application lets you do the following:

* Capture events
* Start activities
* Make phone calls
* Send text messages
* Scan barcodes
* Location
* Use text-to-speech: that is, you can generate accessible messages for blind people!


More information on the project's wiki. I hope to run some tests soon and translate some tutorials.

http://google-opensource.blogspot.com/2009/06/introducing-android-scripting.html
