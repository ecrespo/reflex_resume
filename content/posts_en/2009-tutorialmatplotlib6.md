Continuing with the matplotlib tutorials, this time we will see how to place 2 separate plots.

The code is shown below:

![Matplotlib6 code](./images/matplotlib6-codigo.png)

The necessary modules are imported, a function is defined that returns the result
of a mathematical calculation, and then the time ranges tiempo1 and tiempo2 are defined.

The figure is defined, then the subplot, and the data to build the first
plot is passed to it (tiempo1, the function, the plot label, tiempo2, the function and the
  plot label).

The title is set on the plot, the axis labels for both plots are set,
the second plot is built and both are shown.

The figure shows the 2 plots:

![Matplotlib6 code](./images/matplotlib6-codigo.png)

[link (broken link)](https://github.com/ecrespo/ecrespo.github.io/blob/master/content/code/2009/tutorialmaplotlib6.py).
