Title: Lazarillo - Translator of Spanish text and mathematical operations to the Braille alphabet

translation: true

Today the program that translates the Spanish alphabet and mathematical operations to the Braille alphabet was uploaded to google code.

As the project description on google code says:

Lazarillo is a translator from the Spanish alphabet and mathematical operations to the Braille alphabet. The goal of Lazarillo is to be an easy and simple editor so that the user can do the translations without difficulty.

This program is developed by Andreina Mejia.

So far it has been tested on Debian Squeeze. The plan is to upload a deb and to have the program appear on Python's PyPi.

Here is the link to the [Lazarillo project](http://code.google.com/p/lazarillo-traductor/).

You can download version 1.2 from this [link](https://code.google.com/p/lazarillo-traductor/downloads/detail?name=Lazarillo-1.2.tar.gz&can=2&q=).
