Summary: This article explains how to generate fake data and store it in a database using faker, sqlite and sqlalchemy.

This article builds on parts of a 2012 article, [Abstracting the database engine with the SQLAlchemy ORM and Python](/blog/abstracciondelmotordebasededatosconelormsqlalchemyypython), which explains how to use sqlalchemy and sqlite3 with Python. 

The full faker documentation is available at this [link](https://faker.readthedocs.io/en/master/index.html). This library generates fake data such as names, phone numbers, jobs and countries, among others.  

The idea for this article comes from a Towards Data Science article, [Generating Random Data into a Database Using Python](https://towardsdatascience.com/generating-random-data-into-a-database-using-python-fd2f7d54024e). 



## Installing the required packages and importing the libraries.

Faker and sqlalchemy need to be installed. 

```bash 
pip install Faker sqlalchemy
```

## The code explained 

1. Import the Faker and sqlalchemy libraries 

```python 
from sqlalchemy import *
from faker import Faker
```

2. Create the sqlite database contactos.db and its table with the required fields

The table is created with these fields: 
* id: Id of the inserted record, integer, primary key.
* nombre: Full name, string.
* telefono: Phone number, string.
* pais: Country, string. 
* fecha_nacimiento: Date of birth, string.  
* trabajo: Job, string.  
* correo: Email, string. 

```python 

db = create_engine('sqlite:///contactos.db')
#Se deshabilita el verbose de las ejecuciones. 
db.echo = False
# Se define la metadata
metadata = MetaData(db)
# Se crea la tabla contactos con sus campos.
contactos = Table('contactos',metadata,
    Column('id',Integer,primary_key=True),
    Column('nombre', Unicode(100)),
    Column('telefono',String(11)),
    Column('pais',String(50)),
    Column('fecha_nacimiento',String(20)),
    Column('trabajo',String(50)),
    Column('correo',String(50)))

# Se crea la tabla en la base de datos. 
metadata.create_all()
```

3. Generate the random data and insert it into the database.



```python 
# A continuación se define la instancia de faker con datos localizados para España, Mexico, Italia y Estados Unidos.
fake = Faker(['it_IT', 'en_US', 'es_ES','es_MX'])

# Se crea la instancia para insertar los datos en la tabla contactos.
u = contactos.insert()

# Se generan 300 datos aleatorios falsos. 
# Nombre, telefono, id, país, fecha de nacimiento, trabajo y correo.
for i in range(300):
    u.execute(nombre=fake.name(),
              telefono=fake.phone_number(),
              id=i,
             pais=fake.country(),
             fecha_nacimiento=fake.date_of_birth(),
             trabajo=fake.job(),
             correo=fake.ascii_free_email())

```

4. Query the database. 

Once the data is inserted, a select lists it:

```python 
# Se crea el select para contactos y se ejecuta.
s = contactos.select()
rs = s.execute()
# Se recorre las filas
for fila in rs:
    print (fila)
```
